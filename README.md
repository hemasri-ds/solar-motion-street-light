💡 Smart Streetlight System using Arduino Uno

📌 About the Project

The Smart Streetlight System is an Arduino Uno-based project that automatically controls streetlights using IR sensors. When a vehicle or object is detected, the corresponding streetlight turns ON automatically.

Each streetlight remains ON for 30 seconds and then turns OFF automatically. The system uses three IR sensors to control three streetlights independently, helping to reduce unnecessary electricity consumption.

⚙️ Features

- 🚗 Detects vehicles using IR sensors
- 💡 Automatically turns ON the corresponding streetlight
- ⏱️ Keeps the light ON for 30 seconds
- 🔌 Automatically turns OFF the light to save energy
- 🚦 Controls 3 streetlights independently

🛠️ Components Used

- Arduino Uno
- 3 IR Sensors
- 3 LEDs or Relay Modules
- Connecting Wires
- Power Supply

🔄 How It Works

Vehicle Detected → IR Sensor Activated → Streetlight Turns ON → Waits 30 Seconds → Streetlight Turns OFF

💻 Technologies Used

- Arduino
- Embedded C/C++
- HTML & CSS (for the project website)

🎯 Objective

The main objective of this project is to create an energy-efficient streetlight system that operates automatically based on vehicle movement. It is useful for roads and areas with low traffic.
